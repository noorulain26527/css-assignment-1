# Chic Tartufo Website

A modern and responsive website created using only HTML5 and CSS3. This project focuses on recreating a clean and visually appealing website layout while practicing frontend development and CSS styling.

## 🚀 Features

- Clean and modern design
- Responsive layout
- Navigation bar
- Hero section
- Image sections
- Content cards
- Buttons and hover effects
- Structured sections
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
